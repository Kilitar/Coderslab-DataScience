## 1. Obsah kurzu (dle data-scientist.pdf, str. 12)

### Úvod do Machine Learning
- Úvod do kurzu
- Požadavky a konfigurace prostředí
- Opakování jazyka Python (`numpy`, `pandas`, vizualizační knihovny)
- Statistika ve strojovém učení
- Úvod do strojového učení
- Jak se správně připravit data pro model?

### Regrese
- Regrese
- Lineární regrese
- Regularizace v modelu lineární regrese (Lasso, Ridge, ElasticNet)
- Polynomiální regrese
- Regresní problém s použitím rozhodovacího stromu
- Jak určit kvalitu regresního modelu? Metriky regresních modelů (MSE, RMSE, MAE, R²)
- Jak zlepšit výkon modelu optimalizací hyperparametrů

### Klasifikace
- Metoda nejbližšího souseda (k-NN)
- Logistická regrese
- Klasifikační problém pomocí rozhodovacího stromu
- SVM (Support Vector Machines / Metoda podpůrných vektorů)
- Jak určit kvalitu klasifikačního modelu? Metriky pro klasifikační modely (Accuracy, Precision, Recall, F1-score, ROC-AUC, Confusion Matrix)

### Pokročilé modely strojového učení
- Náhodný les (Random Forest)
- Boosting a bagging
- XGBoost
- Neuronové sítě (Základy neuronových sítí)

### Zpracování přirozeného jazyka (NLP)
- Jak pracovat s textovými daty? (předzpracování, tokenizace, lemmatizace, stopwords)
- Model *Bag of Words* (BoW)
- Algoritmus *TF-IDF*
- Algoritmus *Word2Vec*
- Model *BERT* (Transformer architektura)

### Samostudium a neřízené učení (Unsupervised Learning)
- Snížení dimensionality (PCA, t-SNE)
- Shlukování (Clustering – k-Means, Hierarchical clustering, DBSCAN)
- Detekce anomálií

### Závěrečný projekt a zkouška
- Jak nahrát sešit z Google Colab na Kaggle
- Lineární regrese s regularizací
- Rozhodovací strom (regrese)
- Logistická regrese
- SVM (metoda podpůrných vektorů)
- Závěrečný projekt
- Prezentace výsledků závěrečného projektu
- Zkouška a shrnutí kurzu
