Architecture of scikit-learn models
The scikit-learn library offers many different algorithms that are capable of solving a variety of problems. Nevertheless, the developers of the library have implemented the models in such a way that each of them can be built in a similar way.

Using a simplification, it can be said that building a model consists of 5 basic steps:

Importing the appropriate class from the indicated module of the scikit-learn library.
from sklearn.module import ModelName

Creating an instance of the imported model, which is done by calling the model and assigning it to a variable. The variable should have a descriptive name so that we unambiguously know what our variable is. For machine learning models, it is common to use the word model or an abbreviation of the name of the algorithm we will use (e.g. for linear regression lr, decision tree dt). Of course, you can name the model instance as you see fit.
model = ModelName()

Model training, which is initialized by calling the .fit() method, which takes two arguments. The first argument is the set of independent variables from the training set (X_train), and the second argument is the dependent variable (y_train). After executing the .fit() method, the model is getting trained.
model.fit(X_train, y_train)

Performing a prediction on data that the model has not seen before (X_test) using the .predict() function. As a result, we get the prediction results, which we can assign to the variable y_pred.
y_pred = model.predict(X_test).

Model evaluation, which will tell us how good our model is. For this we use the .score() method, which has implemented one of the basic metrics for evaluating a model - for classification it is accuracy, and for R2 regression.
model.score(X_test, y_test).

The above lines of code are used to understand how the scikit-learn library works. Based on the example given above, we can write code to build a model using scikit-learn:

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)
model.predict(X_test)
model.score(X_test, y_test)

Tools to prepare data for a model in scikit-learn
In addition to the ability to build machine learning models based on the algorithms implemented in the scikit-learn library, we get a number of interesting tools that effectively support the process of creating models:

1. The ability to create synthetic datasets
Scikit-learn has a tool that allows us to create an artificial dataset that we can use to test the whole process, which in English is described by the word pipeline. A pipeline is a combination of several data processing operations that are performed sequentially in a well-defined order. For example, a pipeline for a classification task might look like this:

Data normalization
Dimensionality reduction (removal of redundant variables)
Machine model learning
Pipeline allows you to easily test different variants of data processing and models by changing only some elements of the pipeline, while keeping the rest of the elements unchanged. As we learn about models in a bit more detail, we will also take advantage of this functionality, since the scikit-learn library has implemented a Pipeline() class that allows us to combine multiple data processing steps into a single sequence. In this course we will demonstrate how we can declare and build pipelines.

We can create a synthetic dataset very easily, using the make_classification method:

X, y = make_classification(n_samples=1000, n_classes = 3, n_features = 8, n_redundant = 0, random_state = 42)

2. Scaling variables
The variables in the data we are working with can be of different scales, so in order for our model to produce appropriate results, we need to subject them to scaling. The most common scaling options are:

Normalization (reducing the feature values into the <0, 1> range)
Standardization (all features have a mean of 0 and a standard deviation of 1) In scikit-learn, we can perform normalization using the .normalize() method, and standardization using the StandardScaler() class.
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

3. Creating new variables
A computer, and by extension software based on machine learning, feels most comfortable in a numerical environment. For this reason, the data that goes into the model must be processed beforehand. For example, categorical variables require us to encode them.

We can divide categorical features into:

Ordinal, i.e., those that have a logical order and are related to each other (e.g., loudness scale: quiet, loud, noisy).
Normal, i.e., those that do not have a strict order and are independent of each other (e.g., music genres: rock, pop, rap, metal)
We can implement feature encoding in many ways, such as using Python and creating mappings or using the Pandas library and the .get_dummies() method. What we are interested in is the capabilities of scikit-learn in this regard. And these are considerable, because depending on the need we can use such classes as. OneHotEncoder, OrdinalEncoder or LabelEncoder.

from sklearn.preprocessing import OneHotEncoder
encoder = OneHotEncoder()
X_encoded = encoder.fit_transform(X)

4. Completing empty values
The scikit-learn library also implements tools that allow us to insert specific values where we are missing data. Users have at their disposal the SimpleImputer() class, which, when given parameters, is able to fill in data according to our requirements (e.g. averages of a given variable or a constant or most frequent value).

from sklearn.impute import SimpleImputer
imputer = SimpleImputer(missing_values = np.nan, strategy="mean")
X_imputed = imputer.fit_transform(X)

5. Dividing data into training and test subsets
Any data scientist using the scikit-learn library is familiar with the .train_test_split() method, which randomly splits the data set into training and test sets according to the proportion and random state parameter we set, which will allow us to get exactly the same data split when given the same parameter. For example, each call to the train_test_split() method with random_state equal to 42, will assign the same observations from our initial set to the training and test sets.

from sklearn.model_selection import train_test_split

# test_size = 0.3 means that 30% of data is used for test set, and 70% of data is used for train set

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state = 42)

Scikit-learn also builds on the capabilities of the Pandas library to properly prepare data for the model by implementing such classes as StandardScaler, SimpleImputer and OneHotEncoder.
